# hdlsnip.nvim

Parameterised VHDL templates for Neovim — entities, FSMs, CDC synchronisers,
AXI4-Lite slaves and testbenches, rendered from Lua rather than pasted from a
static snippet file.

> **Status: early development.** Nothing is released and the API is not
> stable. Work in progress lands on `devel`.

## Requirements

- Neovim >= 0.10
- Optional: [LuaSnip](https://github.com/L3MON4D3/LuaSnip),
  `nvim-treesitter` with the `vhdl` parser

## Installation

Not yet — there is nothing to install. The intended shape, with
[lazy.nvim](https://github.com/folke/lazy.nvim):

```lua
{
  "jgonmor16/hdlsnip.nvim",
  ft = { "vhdl" },
  opts = {
    vhdl_std = "2008",
    reset = { style = "async", polarity = "low", name = "rst_n" },
  },
}
```
